# 🎒 Travel Packing Assistant (React 18)

### Описание проекта
Интерактивное веб-приложение для туристов и путешественников, которое помогает структурировать процесс сборов. Приложение позволяет составить детальный список вещей, чтобы ничего не забыть в дороге.

### Основной функционал:
*   ➕ **Добавление и удаление:** Гибкое управление списком вещей для поездки.
*   ✅ **Контроль упаковки:** Возможность помечать вещи как «упакованные» в реальном времени.
*   🧹 **Массовая очистка:** Удаление всего списка одним кликом перед началом нового планирования.
*   🔄 **Интеллектуальная сортировка:**
    *   **By Packed Status:** Сгруппируйте вещи по статусу готовности.
    *   **By Alphabet:** Быстрый поиск предметов в списке от А до Я.
    *   **By Description:** Сортировка по названию/описанию предмета.
    *   **By Input Order:** Отображение вещей в том порядке, в котором вы их добавляли.

### Стек технологий:
*   **React 18** (Hooks, Functional Components, Concurrent Rendering)
*   **JavaScript** (ES6+)
*   **CSS3** (Adaptive UI)
